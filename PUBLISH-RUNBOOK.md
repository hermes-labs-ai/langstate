# Historical publish runbook — do not execute

This document is retained solely to mark prior release instructions as
superseded. It contains no current release authorization and must not be used
to upload, publish, yank, tag, or otherwise alter a public package.

The local branch is the appropriate place to verify a candidate: build an
artifact, install that artifact in an isolated environment, run the documented
first-use path, and compare its public metadata with the intended source. Any
external package action requires a separately owner-armed decision.
